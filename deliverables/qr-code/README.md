# Moorish Xpress business card QR code

Encodes: **https://moorishxpressllc.com** (direct URL, no redirect service, never expires).

| File | Use |
|---|---|
| `moorish-xpress-qr-black.svg` | Vector, preferred for print (business cards, flyers, decals) |
| `moorish-xpress-qr-black.png` | 3000 x 3000 px, high-res raster |
| `moorish-xpress-qr-red.svg` / `.png` | Brand dark red (#B3060C) version, still high contrast |

- Error correction level H (30%), 4-module quiet zone included. Keep the white border when placing it.
- Print at least 0.8 in (2 cm) wide on business cards.
- Tested: all four files decode to https://moorishxpressllc.com.
- The domain must be connected to the website before the QR opens it.
